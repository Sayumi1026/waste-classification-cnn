# Model Evaluation Results

This folder contains the evaluation outputs generated during the waste classification project.

## Included Results

- `model_comparison.png` – Visual comparison of Custom CNN and MobileNetV2 test accuracy.
- `model_comparison.csv` – Numerical comparison of test accuracy and test loss.
- `mobilenet_confusion_matrix.png` – Confusion matrix showing MobileNetV2 classification performance.
- `mobilenet_classification_report.csv` – Precision, recall, and F1-score for each waste category.

These results help evaluate and compare the performance of the developed models.
